# evensvoren.no – personlig CV-side

Innhold:
- `index.html` – selve nettsiden
- `css/style.css` – design og responsiv layout
- `js/script.js` – mobilmeny og dynamisk årstall
- `assets/` – legg CV, bilder og andre filer her

## Før publisering

Bytt ut:
1. E-postadressen i kontaktseksjonen.
2. LinkedIn-lenken.
3. GitHub-lenken hvis du bruker GitHub.
4. Eksempeltekst under arbeidserfaring.
5. Prosjekter slik at de matcher det du ønsker å vise offentlig.

## Test lokalt

Åpne `index.html` direkte i nettleseren.

For lokal webserver med Python:

    python3 -m http.server 8080

Åpne deretter:

    http://localhost:8080

## Publisering

Filene kan publiseres på de fleste webhotell, GitHub Pages, Cloudflare Pages,
Netlify eller egen Linux-server med nginx/Apache.
